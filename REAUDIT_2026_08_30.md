### 2.6 Security & operations

| # | Gap | Severity | Evidence / Why it matters |
|---|-----|----------|---------------------------|
| 2.6.1 | `/api/health` does not report mail transport status | P1 | Only DB + scheduler reported; mail outages are invisible to health checks. |
| 2.6.2 | `/api/lead` uses leftmost `X-Forwarded-For` | P1 | Clients can spoof IP to bypass rate limits. |
| 2.6.3 | No rate limiting on authenticated tRPC mutations | P1 | Expensive admin operations unbounded per IP/user. |
| 2.6.4 | `scryptSync` blocks event loop | P1 | Login stalls Node 50–200 ms; DoS vector. |
| 2.6.5 | Payment success/cancel URLs use request `Origin` | P1 | Attacker can redirect to phishing domain. |
| 2.6.6 | Docker runs as root | P2 | Container compromise grants host root. |
| 2.6.7 | No graceful shutdown / SIGTERM handling | P2 | In-flight requests dropped on restart. |
| 2.6.8 | In-process scheduler not horizontal-safe | P2 | Jobs duplicate/skip with >1 replica. |
| 2.6.9 | `.dockerignore` may leak secrets | P2 | `.env`, `.env.*.local`, `*.pem`, `*.key` not excluded. |
| 2.6.10 | Dependency vulnerabilities | P2 | `npm audit` reports multiple CVEs; CI does not block merges. |
